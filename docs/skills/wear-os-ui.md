# Skill: Wear OS UI на круглом экране

Источники (официальные):
- [Handle different watch shapes](https://developer.android.com/training/wearables/views/layouts) —
  на круглом экране контент в углах обрезается; для Views применяют `BoxInsetLayout`
  с `app:layout_boxedEdges="all"`, для Compose — `Scaffold`/`TimeText` и Compose for Wear OS.
- [Wear OS app quality](https://developer.android.com/docs/quality-guidelines/wear-app-quality)
- [Wear OS design](https://developer.android.com/design/ui/wear)

Скилл применяется, когда делаем/правим экран приложения для Wear OS.

## Профиль нашего устройства

| Параметр | Значение |
|---|---|
| Устройство | OnePlus Watch 2 (`OPWWE231`, Wear OS 4, API 34) |
| Экран | **466 × 466 px, круглый**, плотность 320 dpi |
| Логический размер | **233 × 233 dp** (1 dp = 2 px) |
| Запись занята | 100 % (без chin) |

## Правила (проверять на каждом экране)

**R1. Круг — это граница, а не рамка.** Любой элемент обязан лежать внутри круга:
`dx² + dy² ≤ (R − m)²`, где `R = 233 px`, центр `(233, 233)`, `m = 24 px` (≈10 %).
Для строки с центром `y` допустимая полуширина: `√(R² − (y − cy)²) − m`.

**R2. Ничего важного в углах.** В угловых зонах (расстояние от центра > 0.92·R) —
только фон. Полноширинные нижние панели и подписи по углам запрещены.

**R3. Тап-зоны.** Основное действие — **≥ 48 dp**. Чипсы/вторичные — **≥ 36 dp** визуально;
если меньше 48 dp, добирать отступом строки, а не уменьшать текст.

**R4. Типографика.** Время — тонкий шрифт 40–44 sp; заголовок экрана — 14–16 sp;
основной текст — 12–13 sp; служебный — 10 sp, не меньше 9 sp.

**R5. Один экран — одно решение.** Приложение не должно требовать скролла для главного
действия. Скролл допустим только на вторичных экранах (график/детали).

**R6. Тёмная тема и акцент.** Фон почти чёрный, один акцентный цвет, градиент только
на главном действии. Никаких светлых «карточек на белом».

**R7. Обратная связь.** У любого действия есть видимое состояние: до/во время/после.
Статус пишется словами (`LOG ON`, «не взведён»), а не только цветом.

**R8. Края.** Между контентом и физическим краем — **≥ 20 px** по вертикали
(на часах нижняя дуга съедает больше всего места).

**R9. Ambient / AOD.** В покое (ambient) на экране остаются только время и, при
необходимости, кольцо прогресса: без кнопок, статусов, градиентов и анимаций.
Фон — чистый чёрный, яркость элементов снижена (`dimmed`), частота обновления —
один раз в минуту (`onUpdateAmbient`). Интерактив возвращается в `onExitAmbient`.

## Код-помощник

`RoundScreen.kt` (в проекте):
- `isRound(resources)` — `Configuration.isScreenRound`;
- `safeWidth(centerYpx, fullWidthPx)` — ширина, гарантированно вписанная в круг с отступом;
- `fits(rect)` — проверка прямоугольника на попадание в круг (для тестов верстки).

## Чек-лист перед отправкой экрана

- [ ] Все элементы проходят `fits()` (проверяется юнит-тестом и дампом `uiautomator`).
- [ ] Главное действие ≥ 48 dp и внутри круга.
- [ ] Нет полноширинного элемента в нижних 60 px.
- [ ] Шрифты не меньше 9 sp, время — крупным тонким.
- [ ] Состояния «не настроено / включено / идёт» различимы текстом.
- [ ] Проверено на устройстве: скриншот + координаты из `uiautomator dump`.
