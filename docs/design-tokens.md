# Дизайн-токены: OPW2 (OnePlus Watch 2)

**Единственное поддерживаемое устройство:** круглый экран 466×466 px, 320 dpi → **233×233 dp**.
Квадратные/маленькие экраны и часы с chin не поддерживаем (см. `docs/skills/wear-os-ui.md`).

Всё ниже — источник правды для дизайна и кода. Значения в px (1 dp = 2 px при 320 dpi).

## Типографика (px, шрифт sans, тонкий вес для крупных)

| Роль | Размер | Цвет | Примечание |
|---|---|---|---|
| Время (циферблат) | 92–96 | `text` | thin, letterSpacing 0.01 |
| Крупное число (метрика) | 44–48 | `text` | thin |
| Заголовок экрана | 22–24 | `accent` | caps, letterSpacing 0.16 |
| Подпись элемента | 20–22 | `text_secondary` | |
| Основной текст | 20–22 | `text` | lineSpacing +4 |
| Служебный (файл, версия) | 16–18 | `text_tertiary` | |

Минимум для читаемости на ходу — **≥ 18 px** (9 sp).

## Форма и отступы

- Радиус карточек: **20 dp (40 px)**; кнопки — «капсула» (половина высоты).
- Внутренние отступы карточки: 16 dp по горизонтали, 12 dp по вертикали.
- Между блоками по вертикали: 8–12 dp.
- Безопасный радиус контента: **209 px** от центра (R = 233 − 24); нижняя/верхняя дуги узкие.
- Индикатор разделов: 3 точки, шаг 8 dp, радиус активной 4 px, остальных 3 px, полоса y ≈ 406–426.

## Акценты и состояния

- Взведён: кольцо градиентом `accent_from → accent_to`, точка на конце с мягким свечением.
- Запись идёт: точка пульсирует 1.4 с (дыхание), рядом подпись «запись».
- Не взведён: кольцо `surface_hi`, время `text`, статус `text_secondary`.
- Ambient: всё в `#0A0A0A`, только время (`text_secondary`) и тонкое кольцо `accent_dim`.

## Движение

| Событие | Длительность | Кривая |
|---|---|---|
| Наполнение кольца при взведении | 700 мс | decelerate |
| Пульсация точки записи | 1400 мс, цикл | ease-in-out |
| Доводка свайпа между разделами | 180 мс | decelerate |
| Возврат отменённого свайпа | 140 мс | decelerate |
| Хаптик | тик на изменение, confirm на действии | — |

## Запреты

- Никаких fade-переходов между разделами (только следование за пальцем).
- Никаких элементов в углах экрана и в нижней дуге шире ~140 px.
- Не более **одного** главного действия на экран.
- Никакого ротари/безеля в управлении: только тап и вертикальное движение.
