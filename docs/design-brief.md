# Дизайн-бриф: три экрана OPW2

Устройство одно: **OnePlus Watch 2, круг 466×466 px, 320 dpi** (1 dp = 2 px). Источник правды:
`docs/design-tokens.md`. Правила: `docs/skills/wear-os-ui.md` (R1–R13). Другие экраны не рассматриваем.

## Геометрия (общая для всех экранов)

- Центр `(233, 233)`, R = 233 px, **безопасный радиус 209 px** (R − 24).
- Допустимая ширина полосы `y1..y2`: `2·√(209² − dy²)`, `dy = max(|y1−233|, |y2−233|)`.
- Готовые лимиты: y 200–232 → **412 px**; 244–304 → **393 px**; 314–410 → **222 px**; 406–426 → **160 px**; ниже 442 px — только фон.
- Широкое (> 250 px) — только в средней полосе y ≈ 180–320. В нижней дуге ≤ **140 px** и не ниже y 426.
- Ротари/безель, Compose, fade-переходы, второе главное действие — не предлагаем.

## Экран 3: Статус (вторичный, скролл разрешён)

- Заголовок `СТАТУС`: y 60–92, 22 px caps ls 0.16, `#00D1A9`, cap 260 px.
- Далее вертикальный список строк-карточек: `x` центрирован, ширина **330 px**, высота **56 px**, radius **24 px** (12 dp),
  фон `#111A1E`, обводка 1 px `#1B262B`, интервал между строками **8 px** (шаг 64 px).
- Внутри строки, padding 20 px: **точка-иконка ⌀ 12 px** акцентом `#00D1A9` слева, **подпись 20 px** `#9FB3B8` слева,
  **значение 20 px** `#F2F7F7` справа. Тап-зона строки ≥ 56 px (R3).
- Строки: Будильник · Будильник системы · Повтор и окно · Отложить · Ночной лог · Последний подъём · Батарея · Разрешения · Версия.
- Первые 3 строки видны без скролла (y 104–288); остальное — вертикальным скроллом. Главного действия на экране нет.
- Индикатор разделов (3/3) — y 406–426, как на экране 2; контент скролла получает нижний отступ 56 px.

## Микроанимации и хаптика (строго по токенам)

- Наполнение кольца при взведении: **700 мс**, decelerate; от 0 до текущего прогресса.
- Пульсация точки записи: **1400 мс**, цикл, ease-in-out; амплитуда ⌀ 21 → 44 px.
- Доводка свайпа между разделами: **180 мс**, decelerate; возврат отменённого свайпа: **140 мс**, decelerate.
- Содержимое тянется за пальцем (`translationX = dx`, затемнение до 0.75), старт экрана — slide 220 мс; **fade запрещён**.
- Нажатие кнопки: фон `#18242A` → `#24343A` (0 мс, без fade), при отпускании возврат за 120 мс.
- Ambient: обновление раз в минуту, анимации и пульс выключены (R9).
- Хаптика: `tick` — на изменение значения (окно, дни, страница), `confirm` — на главном действии
  (взвести/снять/остановить) и на подтверждённом свайпе; в ambient — не вибрируем.

## Что улучшаем относительно текущего дизайна

1. **Статус отрывается от часов.** Было: `top = 206` при базовой линии времени 207 px — зазор ≈ 7 px, строки визуально слипались.
   Стало: полоса 200–232 с зазором 20 px → часы и режим читаются раздельно на ходу.
2. **Статус становится читаемым.** Было 13 sp (26 px) `text_secondary` без caps; стало **22 px caps ls 0.12** — по токену «Заголовок/подпись», ≥ 18 px минимум для чтения на ходу.
3. **Главная кнопка дотягивает до tap-target.** Было 240×88 px = 120×44 dp (< 48 dp, нарушение R3); стало 200×96 px = 100×48 dp
   и по лимиту круга в полосе 314–410 (222 px) проходит без ужимания.
4. **Индикатор перестаёт наезжать на кнопку.** Было: точки 406–426, кнопка до 402 → зазор 4 px. Стало: на главном индикатор не рисуем,
   точки остаются на экранах 2–3, где они не конкурируют с действием.
5. **Капсула по токенам, а не «на глаз».** Было 340×56 px, radius 26 dp, сплошной `#1B2529` (цвета нет в палитре — `#18242A` поверхность,
   `#24343A` обводка). Стало 320×60, radius 30, фон/обводка из `surface_hi`/`stroke_hi` → капсула не читается как кнопка.
6. **Карточки и фазы — единые цвета и радиусы.** Было: `bg_card` radius 18 dp, глубокий сон в графике `#7E57C2` (в токенах `#7C6BFF`).
   Стало: радиусы 32/28/24 px (16/14/12 dp), фаза строго `#7C6BFF` → график, легенда и плашки совпадают по цвету.
7. **Плашки метрик вместо простыни текста.** Четыре строки сводки 22 px заменены двумя плашками с числом 44 px: главный факт ночи
   виден за 0.5 с, детали уходят в скролл (R5 разрешает для вторичного экрана).
8. **На экране 3 значение отделено от подписи.** Было `"$key: $value"` одной строкой в 11 sp; стало карточка с подписью слева
   `#9FB3B8` и значением справа `#F2F7F7` + точка-иконка → список сканируется по левому краю, статус читается без чтения целиком.

## Чек-лист приёмки (на устройстве, скриншот 466×466)

- [ ] Ни один элемент не выходит за круг 209 px: кнопка 200×96 в 314–410, капсула 320 px в 244–304, карточка 300 px в 100–300.
- [ ] Зазор время→статус на скриншоте **≥ 20 px**, статус не задевает нижние выносные элементы цифр.
- [ ] Кнопка измеряется линейкой по скриншоту: **96 px** по высоте, 200 px по ширине, radius 48 px (полукруг по краям).
- [ ] Ни одного элемента ниже y 426; в полосе 406–426 на главном нет точек.
- [ ] Статус в каждом из 4 состояний — разные **тексты**, различимые в ч/б (переключить `adb shell am start … --ez force_ambient true`).
- [ ] Ambient: в кадре только время и кольцо, фон `#000000`, кнопки/капсулы/точек нет (R9).
- [ ] Переходы: при свайпе контент идёт за пальцем, доводка 180 мс; fade между экранами не наблюдается.
- [ ] Ни один шрифт < 16 px; крупные числа 44 px, время 96 px, заголовки 22 px.
- [ ] `uiautomator dump`: все bounds внутри `√(dx²+dy²) ≤ 209` от (233, 233).
